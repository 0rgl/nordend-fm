# Changelog

Every release of Nordend, newest first. Nordend stays at 0.x while it is young: a new **minor**
version (0.2.0, 0.3.0…) brings features you can see; a **patch** (0.2.1) only fixes things.
1.0.0 will come once Nordend has been its author's everyday file manager for a while and its
files (`config.toml`, `state.toml`) have settled. Day-by-day notes are in the
[devlog](docs/devlog.md).
